# Simple POS

A simple Point of Sale mobile application built with Expo and Expo Router.

## Features

- Welcome screen
- Login with registered mock accounts
- Product management
- Sales summary
- Inventory monitoring

## Test accounts

- admin@possystem.com / admin123
- cashier@possystem.com / cashier123

## Run

Install dependencies with:

npx expo install

Then start the project:

npx expo start
